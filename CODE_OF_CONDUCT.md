# Code of Conduct

TwitchBatch is a student project. People who use it, report bugs, or send changes should be able to do that without being insulted or pushed out.

## Expected

- Be direct and respectful.
- Comment on the code or the idea, not the person.
- Download only videos you have the right to keep. Do not ask this project to bypass a login or a subscriber wall.

## Not accepted

- Harassment, slurs, or sexual comments.
- Publishing someone else's private videos, passwords, or personal files.
- Spam, scams, or pretending this tool is an official Twitch product.

## If something goes wrong

Open a GitHub issue and describe what happened. The maintainer is [Himanshu-5680](https://github.com/Himanshu-5680). Serious reports can also be sent through that GitHub profile.

Anyone who keeps breaking these rules can be blocked from the repository.
